# Machine Wars v2 — Task List

Execution checklist for [ROADMAP-V2.md](ROADMAP-V2.md). **Each task is sized for one
session** and written to be picked up cold — read this file plus the linked plan section,
not the whole roadmap.

## How to use this file

- Tasks are numbered `P<phase>.<n>`. **Do them in order within a phase.** Where a task
  can run in parallel with its neighbour it says so.
- **Tick the box and add the date** when a task is done. That is the handoff signal to
  the next session.
- **Gates are blocking.** A `🚧 GATE` row must pass before any task in the next phase
  starts. If a gate fails, the plan's stated fallback applies — do not proceed anyway.
- Session-size legend: **S** ≈ one sitting (2–4h) · **M** ≈ 1–2 sessions (4–10h) ·
  **L** ≈ 3+ sessions (10h+, split it when you get there).
- Every task lists **Done when** — a concrete, checkable condition. If you cannot check
  it, the task is not done.

## Session protocol (do this every session)

**Start:** read [HANDOFF.md](HANDOFF.md) → this file → only the plan section your task links to.

**End — all three, in order, no exceptions:**
1. Run the task's verification (usually `node tools/gen-pages.mjs --check` + open an arena).
2. **Commit** with a real message and the `Co-Authored-By` trailer. Never commit `.env`,
   `tools/gis/cache/`, or `tools/tripo-out/`.
3. **Update [HANDOFF.md](HANDOFF.md)** — rewrite "Current state" and "Next session",
   append one line to the log.

**Never end a session with uncommitted work and no handoff note.** If a task is half
done, record exactly where it stopped and what is broken.

## Standing rules (apply to every task)

1. **No bundler, no package.json, no TypeScript in this repo.** The no-build property is
   why iteration is fast. Playwright etc. install in the session scratchpad.
2. **Never hand-edit `play/<slug>/index.html`** — they are generated. Edit
   `play/warzone/index.html` and run `node tools/gen-pages.mjs`.
3. **Never hand-edit `src/version.js`** — generated by `tools/gen-version.mjs`.
4. **Deploy only via `node tools/deploy.mjs`**, never raw wrangler.
5. **Preserve the `ASSET_BASE` / `import.meta.url` pattern** (`src/scenes-data.js:13`) —
   it is what makes paths work at all three page depths.
6. After any task touching `src/scenes-data.js`, `src/scenes.js`, or the page template,
   run `node tools/gen-pages.mjs --check` and open one arena in a browser.
